# MODY PANEL — GitHub + Vercel + Neon

## المطلوب مرة واحدة
1. ارفع المشروع إلى GitHub.
2. اربط الـRepository مع Vercel.
3. من Vercel أضف Neon Postgres.
4. في Environment Variables أضف `AUTH_SECRET` بقيمة سرية طويلة. `DATABASE_URL` يأتي من Neon/Vercel.
5. افتح Neon SQL Editor وشغّل محتوى `schema.sql`.
6. اعمل Redeploy.

الحسابات واللاعبون والشات محفوظون في PostgreSQL بشكل دائم.
الشات يتم تحديثه تلقائيًا كل 2.5 ثانية للمستخدمين المسجلين.
